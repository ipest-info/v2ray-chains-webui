节点

添加节点时填写 SSH 登录信息，然后点「安装」即可自动部署 v2ray。若后台所在机器无法直连某个节点，在「SSH 跳板」中选择一个能连到它的节点。

名称SSH公网 / 内网地址状态v2ray操作

线路

线路 = 用户 → 入口节点 → 中转节点 → 出口节点。修改线路或用户后，点右上角「同步全部配置」下发到各节点。

名称路径端口操作

出口代理

出口代理是线路末端节点之后的最后一站（SOCKS5 / HTTP 代理）。可以设为某条线路的默认出口，也可以单独指定给某个用户。

任务日志

后台域名与 HTTPS 证书（acme.sh）

境内服务器的 80 端口对未备案域名通常不通，请选 DNS 验证。证书到期前 30 天自动续期。
